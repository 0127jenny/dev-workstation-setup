# Dev Workstation Setup

이 저장소는 개발 워크스테이션 구축 미션 결과물입니다.
터미널, Docker(OrbStack), Git/GitHub 환경을 세팅하고 검증합니다.

## 진행 상황
- [ ] 터미널 작업 디렉토리 설정
- [ ] Docker 설치 확인
- [ ] Dockerfile 작성 및 웹 서버 컨테이너화
- [ ] Git/GitHub 연동
      
## 터미널 조작 로그
아래 명령어로 디렉토리/파일 생성, 복사, 이동, 삭제를 수행함.

\`\`\`
$ pwd
/Users/xxx/dev-workstation-mission
$ ls -al
(여기에 실제 출력 붙여넣기)
